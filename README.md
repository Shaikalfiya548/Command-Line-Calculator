Command Line Calculator using Python
Project Overview
This is a simple command-line calculator developed using Python. It performs basic mathematical operations through user input.

Features
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Clear calculation
Exit option
Input validation
Division-by-zero error handling
Repeated calculations using a menu
Technologies Used
Python
Visual Studio Code
Concepts Used
Functions
While Loop
If-Else Statements
User Input
Exception Handling
How to Run
Download or clone this repository.
Open the project in VS Code.
Open the terminal.
Run the following command:
python calculator.py
Expected Output
The calculator displays a menu where users can select mathematical operations and view the results.

Conclusion
This project helped me understand Python fundamentals, functions, loops, conditional statements, and exception handling.
