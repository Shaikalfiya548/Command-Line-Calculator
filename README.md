# Command Line Calculator using Python

## Project Overview
This is a simple command-line calculator developed using Python. It performs basic mathematical operations through user input.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear calculation
- Exit option
- Input validation
- Division-by-zero error handling
- Repeated calculations using a menu

## Technologies Used
- Python
- Visual Studio Code

## Concepts Used
- Functions
- While Loop
- If-Else Statements
- User Input
- Exception Handling

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Expected Output
The calculator displays a menu where users can select mathematical operations and view the results.
